How to Convert Numbers to Words in Excel (Step-by-Step Guide)

No built-in formula exists for this in Excel. But with a quick VBA trick, you can spell out any number in seconds.

Microsoft Excel can sort millions of rows, build financial models, and run statistical analysis. But here's something funny — it can't spell out a number. Seriously. Type 500 into a cell, and there's no formula that returns "Five Hundred." It's been a missing feature for decades, and it still catches people off guard.

So how do you convert numbers to words in Excel? The answer is a VBA macro. By adding a small chunk of code called the SpellNumber function, you can turn any digit into its written English form. It takes under 5 minutes to set up, and it works on every version of Excel from 2007 onward — including Microsoft 365.

This guide walks you through the entire process. You'll get the exact code, step-by-step instructions, and fixes for common errors. Let's get right into it.

Why Excel Doesn't Have a Built-In Number to Words Function

Microsoft Excel does not include a native formula or function to convert numbers to words. Despite having over 500 built-in functions — from VLOOKUP to XLOOKUP, from SUMIFS to LAMBDA — this one has never made the cut.

Why not? Microsoft has never given a clear official reason. However, the likely answer comes down to language complexity. Spelling out numbers varies widely across languages. English alone has quirky rules — hyphens for twenty-one through ninety-nine, the "and" debate between British and American English, and different conventions for decimals and currency. Building a single function that handles all these variations across 100+ supported languages would be a big ask.

That said, Microsoft isn't completely ignoring the issue. Their official support page actually provides a VBA macro code for this exact purpose. They acknowledge that users need it, especially in financial and accounting workflows. They just haven't baked it into the formula bar yet.

So what are your options? There are basically three routes:

  • VBA Macro — The most reliable and widely used method. Works offline and inside your spreadsheet.
  • Third-party add-ins — Downloaded extensions that add this feature. Some are free, others are paid.
  • Online converters — Convert the number on a website and paste the result back into Excel manually.

Among these three, the VBA macro is the clear winner for anyone who works with Excel regularly. It's a one-time setup. Once you add the code, it stays in your workbook forever. And it works on Excel 2016, 2019, 2021, and Microsoft 365 — on both Windows and Mac.

Let's walk through how to set it up.

How to Convert Numbers to Words in Excel Using VBA

The most reliable way to convert numbers to words in Excel is by creating a User Defined Function (UDF) through a VBA macro. Don't worry — you don't need to be a programmer. You're just copying and pasting a block of code. That's it.

Follow these 6 steps exactly:

  1. Open your Excel workbook — This should be the file where you want the number-to-word conversion to work.
  2. Press Alt + F11 — This keyboard shortcut opens the Visual Basic for Applications (VBA) editor. On Mac, press Fn + Option + F11.
  3. Insert a new module — In the VBA editor menu, click "Insert" and then select "Module." A blank white window will appear on the right side.
  4. Paste the SpellNumber code — Copy the full VBA code provided below and paste it into that blank module window.
  5. Save your file as .xlsm — This is very important. Go to File > Save As and choose "Excel Macro-Enabled Workbook (.xlsm)" as the file type. If you save it as a regular .xlsx file, the macro won't work.
  6. Use the function — Go back to your spreadsheet. In any cell, type =SpellNumber(A1) where A1 contains the number you want to spell out. Hit Enter. Done.
⚠️ Important: When you open the file next time, Excel may ask you to "Enable Macros." Always click yes — otherwise the SpellNumber function won't run and you'll see a #NAME? error.

Complete VBA Code for SpellNumber Function

Below is the full VBA code recommended by Microsoft's official support documentation. This code handles whole numbers up to 999,999,999 and decimals up to two places.

VBA CODE
Function SpellNumber(ByVal MyNumber)
  Dim Dollars, Cents, Temp
  Dim DecimalPlace, Count
  ReDim Place(9) As String
  Place(2) = " Thousand "
  Place(3) = " Million "
  Place(4) = " Billion "
  Place(5) = " Trillion "
  MyNumber = Trim(Str(MyNumber))
  DecimalPlace = InStr(MyNumber, ".")
  If DecimalPlace > 0 Then
    Cents = GetTens(Left(Mid(MyNumber, DecimalPlace + 1) & "00", 2))
    MyNumber = Trim(Left(MyNumber, DecimalPlace - 1))
  End If
  Count = 1
  Do While MyNumber <> ""
    Temp = GetHundreds(Right(MyNumber, 3))
    If Temp <> "" Then Dollars = Temp & Place(Count) & Dollars
    If Len(MyNumber) > 3 Then
      MyNumber = Left(MyNumber, Len(MyNumber) - 3)
    Else
      MyNumber = ""
    End If
    Count = Count + 1
  Loop
  Select Case Dollars
    Case ""
      Dollars = "No Dollars"
    Case "One"
      Dollars = "One Dollar"
    Case Else
      Dollars = Dollars & " Dollars"
  End Select
  Select Case Cents
    Case ""
      Cents = " and No Cents"
    Case "One"
      Cents = " and One Cent"
    Case Else
      Cents = " and " & Cents & " Cents"
  End Select
  SpellNumber = Dollars & Cents
End Function

This code also requires two helper functions — GetHundreds and GetTens — which handle the individual place values. You'll find the complete helper code on Microsoft's official support page for the SpellNumber function. Copy all three functions into the same module for everything to work correctly.

How to Use the SpellNumber Function in Excel

After adding the VBA code, type =SpellNumber(A1) in any cell to convert a number to its word form. Replace A1 with whatever cell holds your number. The result appears instantly.

Here are some practical examples:

Cell A1 Value Formula Result
500=SpellNumber(A1)Five Hundred Dollars and No Cents
1250.75=SpellNumber(A1)One Thousand Two Hundred Fifty Dollars and Seventy Five Cents
99=SpellNumber(A1)Ninety Nine Dollars and No Cents
1000000=SpellNumber(A1)One Million Dollars and No Cents

Notice that the default code outputs results in a currency format — Dollars and Cents. If you want a plain number without currency labels, you'll need to tweak the code. Specifically, remove the lines that append "Dollars" and "Cents" and replace them with empty strings.

Want to use Indian Rupees instead? Just change "Dollars" to "Rupees" and "Cents" to "Paise" inside the VBA code. The conversion logic stays exactly the same. Similarly, you can swap in Pounds and Pence for British currency, or Euros and Cents for European formats.

Now, let's cover the two most common errors people run into:

  • #NAME? error — This means Excel doesn't recognize the function. Either the macro isn't enabled, or you saved the file as .xlsx instead of .xlsm. Reopen the file, enable macros, and make sure the file format is correct.
  • #VALUE! error — This usually means the cell you're referencing contains text instead of a number. Make sure the source cell has a numeric value only.

One more thing — the SpellNumber function doesn't update automatically if you change the VBA code. After making edits, press Ctrl + Alt + F9 to force Excel to recalculate all formulas. That'll refresh the output across your entire workbook.

Alternative Methods to Convert Numbers to Words in Excel

Besides VBA, there are two other ways to get numbers spelled out in your Excel spreadsheet. Each has its own trade-offs, so pick the one that fits your situation best.

Method 1: Third-Party Add-Ins

Several add-ins are available through the Microsoft Office Add-Ins store. Some popular ones include "Number to Words" and "Spell Number." After installing, these add-ins typically work like regular functions — just type the formula and get results. The downside? Some are paid, and a few don't support currency formatting or large numbers beyond millions.

Method 2: Online Converters (Copy-Paste)

If you only need to convert a handful of numbers, an online number to words converter works fine. Type the number on the website, copy the result, and paste it into your Excel cell. It's manual, so it doesn't scale well for large datasets. But for quick one-off tasks, it gets the job done.

Frequently Asked Questions

Does Excel have a built-in function to convert numbers to words?

No, Microsoft Excel does not have a built-in function for this. Despite having hundreds of native formulas, number-to-word conversion isn't one of them. The official workaround provided by Microsoft is a VBA macro called SpellNumber. You add it once to your workbook, and it works like any other formula from that point forward.

Will the SpellNumber function work on Mac?

Yes, the SpellNumber VBA function works on Mac versions of Excel. However, some older Mac editions had limited VBA support. If you're running Excel for Mac 2016 or later, you'll have full macro compatibility. To open the VBA editor on Mac, use the shortcut Fn + Option + F11 instead of Alt + F11.

Can this VBA code handle Indian Rupees?

Yes, you can modify the code to handle Indian Rupees with a small edit. Inside the VBA code, find every instance of "Dollars" and replace it with "Rupees." Then find "Cents" and replace it with "Paise." The number conversion logic remains identical — only the currency labels change. Save the file and your function will output amounts in Rupees format.
